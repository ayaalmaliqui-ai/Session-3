# Commandes Git utilisées

## 1. Vérifier l'état du dépôt
```bash
git status
```

## 2. Préparer les modifications
```bash
git add index.html
```

## 3. Enregistrer les modifications
```bash
git commit -m "Ajout du titre principal dans index.html"
```

## 4. Vérifier l'état après le commit
```bash
git status
```

## 5. Envoyer les commits vers GitHub
```bash
git push
```
