Réalisation : Formaliser les fonctionnalités de l’Administrateur
## 1. Règle de nommage (Acteur + Action + Élément) par Entité :

Articles :

L’Administrateur liste les articles.
L’Administrateur ajoute un article.
L’Administrateur modifie un article.
L’Administrateur supprime un article.
Catégories :

L’Administrateur liste les catégories.
L’Administrateur ajoute une catégorie.
L’Administrateur modifie une catégorie.
L’Administrateur supprime une catégorie.
## 2. Exemples de parcours fonctionnels :

Acteur : Administrateur Écran de départ : Page de gestion des catégories Action : Clique sur le bouton “Ajouter une catégorie” Résultat : Affichage du formulaire de création de catégorie

## 3. Synthèse fonctionnelle de la partie admin :

Acteur	Fonctionnalités
Administrateur	Gestion des Articles :
- Lister les articles
- Ajouter un article
- Modifier un article
- Supprimer un article

Gestion des Catégories :
- Lister les catégories
- Ajouter une catégorie
- Modifier une catégorie
- Supprimer une catégorie

## 4. Synthèse fonctionnelle

L'administrateur peut gérer les articles et les catégories. Pour chaque entité, il peut lister, ajouter, modifier et supprimer les éléments.
